CONFIGURAÇÃO VERCEL (Environment Variables):

ADMIN_PASSWORD_HASH = hash gerado por 'node GERAR_HASH_SENHA.js'
SESSION_SECRET = segredo aleatório de pelo menos 32 caracteres
GITHUB_WRITE_TOKEN = token fine-grained com acesso SOMENTE ao repositório
  bancodedadoscreativ-hub/balada-forrozeira, permissão Contents: Read and write
GITHUB_REPO = bancodedadoscreativ-hub/balada-forrozeira
GITHUB_BRANCH = main

PUBLICAÇÃO:
- Vercel deve estar conectada ao MESMO repositório GitHub.
